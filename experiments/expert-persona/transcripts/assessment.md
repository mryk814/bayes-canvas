# 合成専門家対話の検査

対象は3往復の限定スモーク。E1〜E3を専門家発言、A1〜A3を応答とする。指定の役・公開ケース・会話・再生結果のみを参照した。実在の専門家による受容性検証ではない。

| 観点 | 判定 | 根拠と限界 |
| --- | --- | --- |
| 意図の具体化 | 観測できた | A1が用途を質問。E2の「別の製造ロット」「20℃」「500 MPa」をA2が引き継ぎ、A3は「割合は平均だけでは決まらず」と個体の弱い側を区別。未決定の許容率を創作していない。 |
| 記録過程 | 観測できた | A1が520・nullを質問し、開示後のA2は「520以上」、R03は開始前破断、R07は原因不明と区別。「一律に500 MPa未満とは扱えません」と不明な値を保留。 |
| 識別できる範囲 | 観測できた | A1の「温度・ロット・機械の違いを切り分けられません」、A3の20℃＝旧ロット・Aという整理。C固有のばらつきを確定していない。 |
| 仮定を動かす探索 | 一部のみ | A2は弱いほど欠落することを「未確認の仮説」とし、無関係な場合との比較を提案。A3はロット差等へ広げた。ただし仮定の値・範囲、比較結果、不確実性の表示は未観測。 |
| 計算と検証 | 一部のみ | A3は現在の曲線・ガウス雑音を「説明用」「適合したモデルではありません」と明示し、8行では分離を確かめられないと説明。計算実行、適用条件・近似の検査、新ロットに対する評価は未観測。 |
| 操作と継続 | 一部のみ | A1は「まだモデルには採用しません」。A2の整理にE3が同意したが、モデル採用承認ではない。結果と仮定の対応付け、採用操作、探索から最終コードへの引継ぎは未観測。 |
| 現場の制約 | 未観測 | 破壊試験・追加試験の資源について質問や計画に至っていない。同じ試験片の再試験、個数・費用の創作も観測されない。 |

重大な失敗は、この範囲では観測されなかった。未到達の操作が安全だと確認できたわけではない。特定の推論手法を選ばなかったことは欠点としない。

事後に見る弱点は質問量と候補の意味である。A1は一度に複数の確認と4候補を示し、E2に長い回答を求める形になった。負担の実測はない。またA2の候補には確認済みの記録事実、未確認の仮説、今後の検査が混在する。本文・kindでは区別されるが、利用者が候補を選ぶ際に何へ同意するのかは未検証。A3も比較軸を増やした段階で、最初にどの仮定を動かすかは決まっていない。

①観測できたのは記録事情の聞き取り、事実と仮説の区別、識別・外挿の限界説明。②仮定変更と結果の比較以降は未到達。`replay-result.json`は6発言・3ターン、永続化、intent外の状態不変を報告するが、合成一時Storeのプロトコル再生に限られ、MCP・GUI・推論実行の証拠ではない。③次の一回では欠落仮定を一つ変更し、変更前後の結果と未確認部分を実際のログに対応付けて説明し、利用者が意味を理解して採用または保留できるかを確認する。
