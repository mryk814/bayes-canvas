## 未解決の全体範囲

### 接続済み: 保存検査（U16 / RP24）

既存のagent overviewにもモデルごとの検査定義と実行結果の要約を含める。結果の複製値全配列は概要には送らず複製件数を示し、版・run・データの参照と集計値を保持する。これによりClaudeの既存overview取得で保存検査を把握できる。

検査はモデル改訂や知識の確定とは独立した証拠として保存する。画面で区間（両端を含む）・群・平均/最大を指定して確認し、同じ定義を別版のrunへ明示的に再実行する。観測と複製には同じ集計を適用し、全joint drawを一度ずつ使う。複製は形レンズと同様に、新しい観測個体を想定する。スカラーと群プレートの量を固定し、他プレートの潜在量と観測を再生成する。seedを保存し、同じ証拠では再現できるようにする。新しい個体と既存個体の予測を混同しない。

保存する定義はラベル・区間・統計量・x/y列名と単位・群列/添字・元Datasetへの参照を持つ。再実行は同じモデル・同じDataset・同じ列名/単位/群列に限定し、対応が変わる場合は新しい検査を作る。版やrunの置換、過去結果の上書きはしない。結果は版/run/Dataset、seed、観測値・件数、複製値、90%区間、上側割合を保存する。この割合はモデルの合否や校正済みp値ではない。診断不良・旧版も隠さない。

既存JSONを保護するため保存schemaを@3へ進め、@2は検査配列を空で追加して読めるようにする。@1の移行も維持し、読み込みだけでは元ファイルを書き換えない。旧アプリが@3を黙って読み捨てないことを優先する。計算・参照拒否・再読込・旧ファイル移行のテストを先行し、本体の合成fixtureで作成→再実行→履歴表示を検証する。

保存検査の統計量拡張、問い・観測・仮定の契約、pooling、観測シャッター、感度、tail、意思決定、実験計画、時間・空間・生存・GP・逆問題・ML系表現、表現生成比較、利用者評価は引き続き台帳に従って扱う。
この実装束の完了を全体目標の達成とみなさない。
