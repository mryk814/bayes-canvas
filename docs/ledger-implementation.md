# 台帳から本体へつなぐ実装

目標は台帳を基準になるべく多くの機能を実装すること。先行ラボだけを完成条件にはしない。
`research-ledger.md` の未・部分を引き続き対象とし、使える範囲と未検証部分を分けて更新する。

## 今回接続した実装境界（2026-10-08）

- P03 / U12 / RP09: 本体の選択runから同一drawの行を取り出し、モデルの変数・単位・プレート添字を保持して問い合わせる。全drawを分母にし、診断や旧版を隠さない。表示操作はモデルを変更しない。
- P06 / U02: 現在のモデルが要求する入力列・観測列へCSV列を明示対応し、単位・群添字をプレビューしたあと、人の確定でDatasetを保存する。実/合成の区別、来歴、失敗時の原データを保持する。対応できない構造を推測で埋めない。
- U10 / RP11: runの診断値から不足情報・発散・鎖間不一致・有効標本数不足を分けて表示し、次に確かめることを示す。閾値は案内の規則であり、合格やモデルの正しさではない。自動修正はしない。
- U34: モデル版・データ・runを一体のJSONに持ち出し、別の画面で参照と内容の整合を検証できる。取り込み確認は表示のみで、既存の本体モデル・runを書き換えない。改ざん検出署名や推論再実行を保証するものではない。

これらは同じブランチに継続して実装する。Claude側の未コミット変更や実データは操作しない。
本体起動時の確認は専用のテストデータファイル・別ポートで行う。
各計算境界は失敗するテスト→実装→検証の順で進める。

## 確認結果と引き継ぎ

本体の「問いの道具」に4画面を接続した。世界と道具は同じrun選択を共有し、priorから開いた場合はrun未選択のままにする。ツール切替と世界との往復では条件・発言・CSV・貼付JSONを保持し、非表示の標本再生は停止する。別モデル・別runへの変更やブラウザー再読込を越えた道具の入力永続化は対象外。

- 56テスト、型検査、本体build、lab build成功。HTTPテストは使い捨てStoreと自動割当ポートを使い、保存200、不正入力400、旧版409、拒否時の無変更を確認。
- 専用合成StoreでCSVのK→°C、kPa→MPa、群A/B→0/1をプレビューし保存。保存ファイルの再読込でも変換結果と来歴が一致。
- 32行の合成runに対しbias[1]>0とsigma_meas>5のANDが11/32。全標本静止表、再生・停止・ステップ・矢印キー操作、条件付き発言の保存と対話への再表示を確認。
- 診断往復で条件が消える不具合を実画面で再現して修正。修正後は世界との往復も入力を保持し、非表示再生が停止する。prior未選択とrun選択の共有も確認。
- 診断表示、カプセルの正常読込・異なるdataset参照の拒否を確認。1265px/390px幅の画像で余白・折返し・操作部を確認し、狭幅ヘッダーの重なりとCSV表の詰まりを修正。[画像と検証条件](tools-evidence/README.md)。

実MCMC、Claude側の未コミット実装との統合、実データ、CSVファイル選択経路、スマホ実機は未検証。台帳の機能全体は引き続き「部分」とし、今回の本体接続と全体達成を区別する。
