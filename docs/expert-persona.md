# データ専門家ペルソナによる意図解釈の検証

架空の材料試験の担当者を検証役とし、現場知識を持つ人の曖昧な発言を、確認質問と選択可能な解釈へつなげられるか試す。特定のモデルや推論器を選ぶことを唯一の正解にしない。

入力は `experiments/expert-persona/public-case.json`、検証役の非公開背景は `expert.md`、判定基準は `examiner.md`。回答役には公開ケースと実際に交わした発言だけを渡す。検証役は判定基準を読まず、聞かれた現場事情を段階的に明かす。独立した新規コンテキストで実行する。ファイルの分離は実験手順であり、アクセス制御や実際の人間との同等性を保証しない。

対話ログを保存し、別の評価者が根拠となる発言と未検証点を記す。さらにログを専用一時Storeの `createIntent / reply / followUp` で再生し、候補を出すだけではモデル版・データ・推論結果・確定知識が変わらないことを検査する。原本データやClaudeの進行中ファイルには書き込まない。

今回は冷たいコンテキストでの対話1回とStore再生をスモーク検証とする。MCP接続、GUI操作、指差し、CSV取込、実推論、実際の研究者による受容性は別の検証である。発言に含まれる現場事情も合成の設定であり、実世界の測定結果とは呼ばない。

## 今回の実行

2026-10-08、履歴を継承しない専門家役と回答役で3往復し、[会話ログ](../experiments/expert-persona/transcripts/smoke.json)を保存した。回答役に非公開背景・判定基準は渡していない。設定モデルを継承しており、正確なモデルID・sampling設定は記録していないため、発言の完全再現性は主張しない。

実Storeで6発言と最終候補4件の保存・再読込を確認。意図以外の全状態が不変であることを検査した。[再生結果](../experiments/expert-persona/transcripts/replay-result.json)。新規4テストを含む全157テスト・型検査成功。数値テストの成功と対話の評価は別である。

[独立評価](../experiments/expert-persona/transcripts/assessment.md)では、記録過程・利用目的・識別限界の説明を観測できた。質問の多さ、確認済みの事実／仮説／次の検査を候補として選ぶ意味は改善候補。仮定を変えた実計算、採用・保留、破壊試験の制約に基づく追加計画には未到達であり、「意図を汲み取れること全体が合格」とは扱わない。

[実行手順](../experiments/expert-persona/README.md)を使って別の回答モデルでも再試行できる。専門家役の定義は `.cursor/agents/materials-expert.md` にも置いたが、今回の実行は明示的なプロンプトで起動したもので、各ホストによる自動検出は未確認。
