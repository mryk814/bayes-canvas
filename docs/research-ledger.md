## 避けたい失敗（前 Atlas K01–K20）との関係

- K12 AI の長い説明を監査記録とみなす → 監査は版・知識・run の結びつきで行い、説明文には頼らない
- K17 pixel と自然言語だけを agent へ公開 → 世界は ID と数値で、指した対象は model 単位で渡す
- K14 すべての変更に人の確認 → 表示と知識には確認を求めず、モデルの変更だけ採用を求めている
- K13 毎回まったく違う画面 → 2 例とも同じ文法。ただし生成 UI がないので、まだ試されていない
